ABOUT THE PROJECT

Geographic data for
better discovery.

CareAtlas demonstrates how an external geographic API can power a Web GIS. Users can explore mapped healthcare facilities, filter results, and inspect the attributes available for each location.

⌁

Live API retrieval

JavaScript fetch requests retrieve facility data from the OpenStreetMap Overpass API.

◎

Interactive mapping

Leaflet displays facility locations, map layers, popups and selected locations.

⌕

Explore & filter

Search by name or location and filter facilities by healthcare category.
